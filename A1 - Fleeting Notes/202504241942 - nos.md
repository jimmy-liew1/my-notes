In the context of Nutanix, NOS stands for **Acropolis Operating System (AOS)**, formerly known as NOS.  It's the base software or the Acropolis operating system (AOS) that runs on each [Controller Virtual Machine (CVM)](https://www.google.com/search?client=firefox-b-d&cs=1&sca_esv=9c7ec454ad9eda0c&q=Controller+Virtual+Machine+%28CVM%29&sa=X&ved=2ahUKEwjp6efgyvCMAxXzZmwGHVpxOFQQxccNegQIBBAB&mstk=AUtExfAsAUTIb6QeTzfpAjcFgvyN-_su3N0oqWyPJT2EVW2q2e4fgR8yHbMUYlzx5kNVovDfPmQtJRaTIWm88sx1_lcO-7HJy8PA2lUZQ2S7dnmvE4iVMOU0JVqJSbG1QmSy8lQ&csui=3) within a Nutanix cluster, managing and orchestrating the hyper-converged infrastructure. 

Here's a more detailed breakdown:
- **AOS (Acropolis Operating System):** This is the core software that powers the Nutanix platform. It encapsulates the run-time for storage, compute, security, and network services. 
- **Formerly NOS:** The term NOS was previously used to refer to the same software. 
- **[CVM](https://www.google.com/search?client=firefox-b-d&cs=1&sca_esv=9c7ec454ad9eda0c&q=CVM&sa=X&ved=2ahUKEwjp6efgyvCMAxXzZmwGHVpxOFQQxccNegQIDRAB&mstk=AUtExfAsAUTIb6QeTzfpAjcFgvyN-_su3N0oqWyPJT2EVW2q2e4fgR8yHbMUYlzx5kNVovDfPmQtJRaTIWm88sx1_lcO-7HJy8PA2lUZQ2S7dnmvE4iVMOU0JVqJSbG1QmSy8lQ&csui=3) (Controller Virtual Machine):** Each node in a Nutanix cluster has a CVM, which acts as the local storage controller and participates in cluster-wide operations. 
- **[Hypervisor](https://www.google.com/search?client=firefox-b-d&cs=1&sca_esv=9c7ec454ad9eda0c&q=Hypervisor&sa=X&ved=2ahUKEwjp6efgyvCMAxXzZmwGHVpxOFQQxccNegQIDhAB&mstk=AUtExfAsAUTIb6QeTzfpAjcFgvyN-_su3N0oqWyPJT2EVW2q2e4fgR8yHbMUYlzx5kNVovDfPmQtJRaTIWm88sx1_lcO-7HJy8PA2lUZQ2S7dnmvE4iVMOU0JVqJSbG1QmSy8lQ&csui=3):** AOS includes a built-in hypervisor called [Acropolis Hypervisor (AHV)](https://www.google.com/search?client=firefox-b-d&cs=1&sca_esv=9c7ec454ad9eda0c&q=Acropolis+Hypervisor+%28AHV%29&sa=X&ved=2ahUKEwjp6efgyvCMAxXzZmwGHVpxOFQQxccNegQIHBAB&mstk=AUtExfAsAUTIb6QeTzfpAjcFgvyN-_su3N0oqWyPJT2EVW2q2e4fgR8yHbMUYlzx5kNVovDfPmQtJRaTIWm88sx1_lcO-7HJy8PA2lUZQ2S7dnmvE4iVMOU0JVqJSbG1QmSy8lQ&csui=3). 
- **Foundation:** The [Foundation](https://www.google.com/search?client=firefox-b-d&cs=1&sca_esv=9c7ec454ad9eda0c&q=Foundation&sa=X&ved=2ahUKEwjp6efgyvCMAxXzZmwGHVpxOFQQxccNegQIEhAB&mstk=AUtExfAsAUTIb6QeTzfpAjcFgvyN-_su3N0oqWyPJT2EVW2q2e4fgR8yHbMUYlzx5kNVovDfPmQtJRaTIWm88sx1_lcO-7HJy8PA2lUZQ2S7dnmvE4iVMOU0JVqJSbG1QmSy8lQ&csui=3) tool is used for initial cluster creation and imaging of bare metal nodes.
