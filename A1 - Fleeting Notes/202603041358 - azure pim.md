**Azure PIM (Azure Privileged Identity Management)** is a security service in Microsoft Entra ID (formerly [[azure active directory|Azure AD]]) that helps organizations manage, control, and monitor access to important Azure resources. It provides **just‑in‑time (JIT)** elevation of privileged roles so users only have high‑level permissions when they actually need them — reducing risk from standing admin access.
### What Azure PIM Does
- Azure PIM allows users to **elevate permissions in Azure while keeping a security focus**.
- It enables users to elevate access **only when needed**, with controls such as time limits, restricted scope, and approvals. This helps maintain a strong security posture by avoiding permanent, overly broad admin rights.
- The strategy is to **limit the number of permanently assigned high‑level privileges** in Azure, relying instead on temporary elevation via PIM.

### Key Benefits
- **Least privilege access** — users only receive the minimum permissions needed, for the minimum time.
- **Just‑in‑time role activation** — access is granted temporarily, reducing attack surface.
- **Approval workflows** — admins can require justification and approval before granting elevated access.
- **Audit and notifications** — PIM sends emails to approvers and provides logs for compliance and monitoring.

### Typical Use Case
Example from the document:
- Setting up a Contributor role that users can temporarily elevate to on a specific subscription (e.g., Rubrik Outpost).
