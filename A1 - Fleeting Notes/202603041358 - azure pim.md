**Azure Privileged Identity Management (PIM)** is a security service in Microsoft Entra ID (formerly [[azure active directory|Azure AD]]) that enable organizations to manage, control, and monitor access to important resources in organization.  These resources include resources in Microsoft Entra ID, Azure, and other Microsoft Online Services such as Microsoft 365 and Microsoft Intune.

## What is Privileged Identity Management?
Privileged Identity Management (PIM) provides **time-based** and **approval-based** role activation to mitigate the risks of excessive, unnecessary, or misused access permissions on resources.  So that, users only have high-level permissions when they actually need them - reducing risk from standing admin access.  Here are some of the key features of PIM.

Manage, control, and monitor access to important resources. [^1]
- Provide **just-in-time** privileged access to resources and directory.
- Assign **time-bound** access to resources using start/end dates.
- Require **approval** to activate privileged roles.
- Enforce **multi-factor authentication** to activate any role.
- Use **justification** to understand why users activate.
- Get **notifications** when privileged roles are activated.
- Conduct  **access reviews** to ensure users still need roles.

### What Azure PIM Does
- Azure PIM allows users to **elevate permissions in Azure while keeping a security focus**.
- It enables users to elevate access **only when needed**, with controls such as time limits, restricted scope, and approvals. This helps maintain a strong security posture by avoiding permanent, overly broad admin rights.
- The strategy is to **limit the number of permanently assigned high‑level privileges** in Azure, relying instead on temporary elevation via PIM.

### Key Benefits
- **Least privilege access** — users only receive the minimum permissions needed, for the minimum time.
- **Just‑in‑time role activation** — access is granted temporarily, reducing attack surface.
- **Approval workflows** — admins can require justification and approval before granting elevated access.
- **Audit and notifications** — PIM sends emails to approvers and provides logs for compliance and monitoring.

### Typical Use Case
Example from the document:
- Setting up a Contributor role that users can temporarily elevate to on a specific subscription (e.g., Rubrik Outpost).
