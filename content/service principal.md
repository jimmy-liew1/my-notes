A **service principal** is essentially an **identity for an application or service** within [[Azure AD|Azure Active Directory (Azure AD)]]. Think of it as a **service account in the cloud**. Applications can use service principals to authenticate to Azure AD and gain access to Azure resources, such as [[Azure Blob Storage]] or [[Azure Key Vault]], or to applications integrated with Azure AD.
