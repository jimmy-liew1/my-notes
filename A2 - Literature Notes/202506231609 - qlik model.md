Qlik model doesn’t just present a definition framework for [[data literacy|Data Literacy]], but it also goes further and points out the following data literacy characteristics which are considered to be fundamental for a person or an organization to consider itself Data Literate: 

1. **Data Fluency**: utilize the language, vocabulary, and conversational skills that go along with data literacy
2. **Analytical Skills**: utilize and develop analytical thinking skills, utilizing proper problem-solving techniques
3. **Statistical Methodologies**: Data literacy culture utilizes and embraces statistics within the organization
4. **Data Visualizations**: help simplify data, enabling various skill sets to absorb and utilize data.
